# Security Policy

## Supported versions

Pulse is pre-1.0. Security fixes are applied to the latest published framework version on the default branch.

| Version | Supported |
|---------|-----------|
| 0.17.x  | ✅ |
| < 0.17  | ❌ |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report privately using **GitHub Security Advisories**:

1. Open https://github.com/iam-mrkeyboard/pulse-js/security/advisories
2. Click **New draft security advisory**
3. Describe the issue, impact, and (if possible) a minimal reproduction

We will acknowledge the report, assess impact, and coordinate a fix and disclosure timeline with you.

If you cannot use Security Advisories, contact the maintainer through a private channel listed on their GitHub profile—still avoid posting exploit details publicly.
